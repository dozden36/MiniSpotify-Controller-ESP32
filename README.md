# SpotiyT1

A quick little project I built to show my currently playing Spotify song on a TTGO T Display and control playback with a IR remote.

## Features
* Shows track name and artist
* Pprogress bar
* Play / Pause / Next / Prev / Shuffle control via IR

## Wiring
* **IR Receiver Pin:** GPIO 26

## Libraries Needed
* `TFT_eSPI`
* `ArduinoJson`
* `IRremote`

Feel free to tweak the code or change the IR codes to match your own remote!
